# ローカルタスク管理アプリ

Windows向けの、完全ローカルで動作するタスク管理アプリです。

## 現在実装されている機能

- タスクの登録、編集、完了（完了済みタスクも編集可能）
- 「今日やる」、すべて、期限切れ、完了済み・取り消しの表示切り替え
- 期限とは別の「今日やる」指定と、本日期限タスクの自動表示
- 完了直後の「元に戻す」と完了済みタスクの復旧
- ゴミ箱への移動、復元、完全削除、30日後の自動削除
- タスク名、メモ、現在の進捗、進捗率、状態、重要度、期限、カテゴリの保存
- 期間・曜日・祝日有無を指定した繰り返しタスクの一括生成
- サブタスクの追加、編集、完了、削除と詳細画面での進捗表示
- 1ファイル50MBまでの添付ファイル追加、表示、削除
- 重要度別の標準リマインドとタスクごとの個別リマインド
- Windows通知のクリックによるタスク表示、10分・1時間スヌーズ、通知からの完了
- 完了後365日の標準保存と、タスクごとの1～3650日・無期限設定
- メモと分けた上書き式の進捗状況と、0～100%の手動進捗率
- タスク一覧
- 月カレンダーの「日付 → 当日タスク → 詳細」表示
- カレンダーで選択した日付を引き継ぐタスク追加
- `Ctrl + Alt + N` で右端タスク追加を直接開閉
- `Ctrl + Alt + T` で右端タスク表示を直接開閉
- `Ctrl + Alt + N` が他のアプリと競合する場合は `Ctrl + Alt + A` へ自動切り替え
- 180px・240px・320pxを切り替えられる全高・タイトルバーなしの右端パネル
- 右端パネル内の期限別グループ、タスク詳細、追加、全表示の切り替え
- 右端の詳細から、同じパネル内でタスクの全項目を編集・保存
- 右端追加から詳細入力への入力内容引き継ぎ
- カテゴリの追加、名称変更、色変更、削除
- 30分単位の期限時刻プルダウンと直接入力
- 小さい画面やWindowsの表示倍率を考慮したスクロール対応
- Windowsログイン時の自動常駐と二重起動防止
- デスクトップショートカット
- ダーク/ライト表示と11種類のカラーパレット
- `D:\TaskManager\Data\tasks.db` へのローカル保存
- 添付ファイルの `D:\TaskManager\Data\attachments` へのローカル保存

## Windowsでの初回セットアップ

### 前提

- Windows 11
- Python 3.12.2
- `D:` ドライブを利用できること
- pipからPythonパッケージを導入できる

### 手順

1. Gitでリポジトリを取得するか、ZIPをダウンロードして展開する。
2. プロジェクトフォルダーを `D:\TaskManager\App\Task-Manager` へ配置する。
3. `scripts\setup_windows.cmd` をダブルクリックする。
4. `Task manager setup completed.` と表示されるまで待つ。
5. `scripts\run_windows.cmd` をダブルクリックする。

仮想環境はアプリフォルダー内の `.venv` へ自動作成されます。DBはアプリ本体と分けて `D:\TaskManager\Data` へ保存されます。セットアップ時にデスクトップへ `Task Manager`、`Task Add`、`Task List` のショートカットが作成されます。

既存の`tasks.db`は起動時に自動更新されます。進捗項目を追加する更新でも、登録済みタスクはそのまま維持されます。

## 普段の使い方

アプリはWindowsログイン時に画面を出さず、通知領域へ常駐します。

- タスクを追加する: `Ctrl + Alt + N`
- タスクを確認する: `Ctrl + Alt + T`
- 同じショートカットをもう一度押す: 右端パネルを閉じる
- 右端パネル上部の `↔`: 幅を180px、240px、320pxの順に変更
- 全表示を開く: デスクトップの `Task Manager`、または通知領域のチェックアイコン
- 完全に終了する: 通知領域のチェックアイコンを右クリックし、「完全終了」

右端パネルの `×` や全表示画面の `×` ではアプリは終了せず、通知領域へ戻ります。

`Ctrl + Alt + N`を登録できない場合は、起動時にWindows通知を表示し、タスク追加を`Ctrl + Alt + A`へ自動的に切り替えます。通知領域メニューにも現在使用できるキーを表示します。

全表示画面では、左側の「今日やる」「すべて」「期限切れ」「完了済み」「ゴミ箱」から表示対象を切り替えます。「今日やる」には、期限とは別に今日の作業対象へ指定した未完了タスクと、本日が期限の未完了タスクを表示します。本日期限のタスクは「今日やる」指定を解除できません。期限が後日または期限なしのタスクは、追加・編集画面のチェック、全表示の詳細、右端の詳細から「今日やる」へ追加・解除できます。指定は当日だけ有効で、翌日には自動的に今日の一覧から外れます。

タスクを完了した直後は8秒間「元に戻す」が表示されます。時間が経過した場合も「完了済み」から復旧できます。

詳細欄の「ゴミ箱へ」でタスクを移動できます。ゴミ箱内では「復元」と「完全に削除」を選べます。ゴミ箱へ移動して30日を過ぎたタスクは、起動時および1時間ごとの確認で自動削除されます。

タスクの追加・編集画面では「現在の進捗」と「進捗率」を入力できます。進捗率は0～100%を直接入力でき、矢印操作では5%単位で変更します。100%にしてもタスクは自動完了せず、完了状態とは独立して管理されます。

右端パネルでは、タスクの「詳細」から「編集」を押すと、タスク名、メモ、現在の進捗、進捗率、状態、重要度、カテゴリ、期限、リマインド、保存期間、サブタスク、添付ファイルをその場で変更できます。入力項目だけが縦にスクロールし、保存とキャンセルは画面下部に固定されます。編集中にパネルを隠した場合は入力内容を保持し、詳細へ戻る場合は未保存内容の破棄を確認します。

## 繰り返し・サブタスク・添付

全表示のタスク追加画面で「期間と曜日を指定して繰り返し作成」を有効にすると、開始日から終了日までの指定曜日についてタスクをまとめて生成します。「祝日にも作成」が無効な場合は日本の祝日を除外します。次回分を後から自動生成する方式ではなく、保存時に対象期間分を一括生成します。生成後は1件ずつ編集できるほか、編集画面のチェックを有効にすると、共通項目とサブタスクを同じグループの未完了タスクへまとめて反映できます。各回固有の進捗、状態、添付ファイルは一括上書きしません。

サブタスクはタスク追加・編集画面と右端編集画面から追加できます。チェック状態と完了数は全表示・右端の詳細画面に表示されます。添付ファイルも同じ編集画面から追加・表示・削除でき、ファイル本体はDBとは別に`attachments`フォルダーへ保存されます。

## リマインドとWindows通知

リマインドは「標準（重要度に連動）」「個別設定」「通知しない」から選べます。標準設定では9～17時を通知時間帯とし、日付だけの期限は当日15時から、時刻付き期限は24時間前からを基本にします。通常以上は1時間ごと、最優先は期限3時間前から30分ごと、超最優先は期限3時間前から10分ごとに通知します。最優先・超最優先は前日17時にも通知します。

個別設定では通知開始、通常間隔、期限直前の開始と間隔を、それぞれ「日・時間・分」に分けて入力できます。画面には「1日前」「3時間前から」「10分ごと」のような読みやすい表記も表示します。保存形式は従来どおり分単位のため、既存の個別設定は自動的に新しい入力表示へ変換されます。通知時間帯と前日17時通知も変更できます。

通知をクリックすると全表示で該当タスクを開きます。通知領域メニューから最後の通知を10分後または1時間後に再通知したり、タスクを完了したりできます。再通知予約はアプリを再起動しても保持されます。通知の自動表示時間は5・15・30・60秒から選択でき、標準は15秒です。

## 保存期間

完了・取り消しタスクの保存期間は標準365日です。タスクごとに1～3650日または無期限へ変更できます。保存期間を過ぎると自動的にゴミ箱へ移動し、その30日後に完全削除します。確認は起動時と1時間ごとに行います。

- `Ctrl + F`: 検索欄へ移動
- `Ctrl + N`: 全表示画面からタスクを追加
- `Ctrl + Enter`: タスク編集画面、右端の編集画面、または右端追加画面で保存

## カラーテーマ

全表示画面の左下、または通知領域メニューの「カラーテーマ」から変更します。ダーク／ライトと、次の11種類のパレットを自由に組み合わせられます。

- デフォルト
- Cocoa Dusk
- Blue Horizon
- Blush Harmony
- Violet Dream
- Cotton Bloom
- Earthy Moss
- Crystal Mist
- Candy Pop
- Midnight Linen
- Rosy Overcast

選択内容はDBへ保存され、次回起動時にも引き継がれます。画面上に固有のアプリ名や文字ロゴは表示しません。

## 起動できない場合

`scripts\run_debug_windows.cmd` を実行し、表示されたエラー文を確認します。画面を閉じるまでコンソールは消えません。
